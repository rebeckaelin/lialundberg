# Lia Lundberg

A modern, responsive personal website built with React and Vite.

## About

This is a personal portfolio website showcasing her work in writing, her services as a therapist & healer, and information about Lia Lundberg. The site is built with modern web technologies to deliver a fast and engaging user experience.

## Tech Stack

- **React** - Component-based UI library with modern hooks and functional components
- **Vite** - Fast build tool and development server with lightning-fast HMR
- **Tailwind CSS** - Utility-first CSS framework for rapid, responsive styling
- **Sanity.io** - Headless CMS allowing the client to easily update content

## Features

- ⚡ Lightning-fast performance
- 🎨 Modern, responsive design
- 📱 Mobile-friendly interface
- ✨ Clean, maintainable code structure
- 📝 Easy content management through Sanity CMS
